このサイトは検証用である。[research リポジトリの `okf-poc/`](https://github.com/nandemo-ya/research/tree/main/okf-poc) にある OKF v0.2 バンドルと**同じ知識**を、Mintlify から配信している。

同じ内容を二つの経路で配ると何が変わるのかを測るために置いた。比べたいのは次の三点である。

- OKF の frontmatter（`type` / `generated` / `sources` / `stale_after`）を保ったまま Mintlify に載るか
- 生成される `llms.txt` / `skill.md` / MCP が、バンドルを直接読ませるのに対して何を足すか
- エージェントから引いたときの精度と、消費するトークン
